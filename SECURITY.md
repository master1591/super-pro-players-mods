# Security policy

Use only installer commands published in this repository or the official SUPER PRO PLAYERS Discord.

Do not post exploit details publicly. Report suspected vulnerabilities privately to SUPER PRO PLAYERS staff through the official Discord, and include the manager version, BombSquad version/API, platform, and steps to reproduce. Never send passwords, tokens, or other account secrets.

Only APIs 6–9 are supported by the current beta. Security fixes may require users to rerun the newest verified install command and restart BombSquad.
